# V1.2 随机选号与 UI 重构推进记录

状态：已完成
立项日期：2026-08-25
完成日期：2026-08-25
发布版本：`1.2.0 (4)`
目标平台：Android、iOS

## 完成范围

- 为大乐透和双色球生成符合现行单式号码规则的随机号码。
- 支持期数、每期注数和受控跨期模式，不提供购彩、金额建议或概率优势承诺。
- 把单一首页调整为可持续承载 V1.2 至 V1.5 的一级导航，不在首页继续堆叠功能按钮。
- 保持 V1、V1.1 的票据确认、官方证据、失败关闭和本机记录契约不变。

## 已冻结契约

| 项目 | V1.2 边界 |
|---|---|
| 彩种 | 超级大乐透、双色球 |
| 期数 | `1..20` 个相对期次，不绑定官方期号 |
| 每期注数 | `1..10` 注 |
| 单次总量 | 最多 `200` 个投注实例 |
| 大乐透跨期模式 | 所有期次复用同一批随机注单 |
| 双色球跨期模式 | 复用同一批注单、每期独立随机 |
| 重复语义 | 单注区域内禁止重复；注单之间或期次之间允许自然偶合 |
| 存储 | 当前会话内保留，不写入已确认票据表 |
| 文案 | 仅供娱乐，不代表预测，不构成购彩建议 |

## 功能与交互

- 新增可注入整数随机源的领域生成器，使用无放回抽样生成单注号码。
- 大乐透输出五个前区和两个后区号码；双色球输出六个红球和一个蓝球，所有号码升序展示。
- 增加两种彩票大样本合法性、跨期复用、双色球独立模式、大乐透模式阻断、数量边界和固定种子频次健全性测试。
- 冻结一级导航为“核对、选号、记录”；移动端使用底部导航，宽屏使用侧边导航。
- 实现可扩展一级目的地和响应式应用外壳，将“核对”和“记录”收敛为独立工作区。
- 重组核对首页的票面来源、隐私与结果边界，移除重复的记录入口和开发平台信息。
- 实现会话内选号配置、生成、重新生成和状态保留，配置变化会主动清除不再匹配的旧结果。
- 完成彩种分段控件、期数与每期注数步进器、双色球跨期模式、相对期次切换和红蓝号码分区展示。
- 控制器测试确认随机方案不会写入票据仓库；一级页面切换后，本次会话结果仍可恢复。
- Android 与 iOS 版本统一升级为 `1.2.0 (4)`，覆盖升级基线固定为 `1.1.0 (3)`。
- V1、V1.1 的旋转、最大字号、手动录入、记录管理和跨端导入导出专项已适配新版一级导航。

## 完成结论

- V1.2 冻结范围内没有进行中或未完成项，个人自用双虚拟机基线完成关闭。
- 随机选号与已购票据在数据语义和存储上保持隔离，不修改 V1.1 的 Room 模式或逻辑包格式。
- Android 产物使用验收签名；iOS 产物为 Simulator 本地签名 `.app`。生产证书、IPA、商店材料、真机矩阵和公开分发不在本次关闭范围内。
- V1.3 尚未开始，必须先解决历史开奖数据长期存储、分析和展示授权，再单独立项。

## 明确不做

- 不生成或猜测官方期号，不把随机方案直接送入中奖查询。
- 不提供代购、自动购彩、投注金额建议、收益承诺或提高中奖概率的描述。
- 不修改 V1.1 的 Room 票据模式和逻辑导入导出格式。
- 不提前实现 V1.3 的历史数据、图表、数学预测或 V1.4/V1.5 的 AI 能力。
