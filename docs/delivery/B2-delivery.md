# B2 开奖查询与规则引擎交付记录

记录日期：2026-08-24

## 状态结论

B2 核心代码、离线契约测试、跨平台构建和每种彩票 20 个真实期号的机器首轮对账已经完成，并按 ADR-018 纳入个人自用 V1 已关闭基线。固定台账第二人独立复核、两种彩票各连续 6 个真实开奖窗口采样和数据授权仍是对外可靠性声明或未来公开分发的前置条件，不再阻塞 V1.1。B5 已将仓库接入 Android/iOS 完整流程，两端系统网络栈均已完成大乐透历史 PDF 双证据验证；应用仍不得替代实体票兑奖，未知规则或证据不足时继续失败关闭。

## 已实现范围

- 实现 `DLT_2026_01` 和 `SSQ_2026_01` 规则版本选择，生效边界分别为大乐透 `26014` 和双色球 `2026014`。
- 穷举实现大乐透 18 种、双色球 14 种命中组合；双色球特别规定期间额外支持三红零蓝福运奖。
- 实现单式、多注单式、倍数和大乐透追加计算；浮动奖金、追加奖金和福运奖金额只读取当期开奖数据，金额全程使用分单位整数。
- 奖金尚未发布时保留中奖奖级但不承诺金额；发布中、证据不足、政策未知、期号不一致或规则不支持时，绝不输出未中奖。
- 实现体彩和福彩 Ktor 适配器，支持精确单期请求、宽松 JSON 解析和严格领域校验。
- 奖级按语义标识解析，不依赖数组下标；字符串、数字、空值和空对象的类型漂移均在适配层处理。
- 实现主源与辅助源的一致性校验、明确发布字段校验、规范化 SHA-256，以及内存修订和冲突检测；双官方数据面已发布且一致时不再使用固定时间闸门延迟结果。
- `null` 奖金补全为官方金额视为正常发布进展；改号、改注数、已有金额变化、记录消失或完整性回退均进入冲突状态。
- 原始官网响应不缓存、不打印、不持久化；离线测试只使用人工最小化的同结构夹具，未保存福彩原始响应。
- 提供默认不联网的真实官网 smoke 测试入口，只有显式设置环境变量后才执行两个单期查询。
- 大乐透官方公告语义解析已移到共享代码；JVM 验收使用 PDFBox 3、Android 使用 PDFBox Android、iOS 使用系统 PDFKit，三端共用同一失败关闭契约。Android 运行时显式排除了本功能不需要的 BouncyCastle 加密依赖。

## 数据源边界

### 大乐透

- 历史开奖接口作为主源；目标为最新一期时，使用最新开奖聚合接口作为独立辅助证据。
- 非最新历史期没有可直接解析的独立官方 JSON 证据，官网静态详情页在核查时返回 404，机器对账改用每期 `https://pdf.sporttery.cn/33800/{issue}/{issue}.pdf` 官方公告。
- 移动 Repository 在最新开奖聚合接口不含目标历史期时使用 PDF 作为独立证据；聚合接口实际返回目标期且审核、公告字段完成时，只需与历史 JSON 严格一致即可首次形成终态，不再冗余下载同一期 PDF。历史 PDF 响应继续限制类型、最终 URL 和最多 1 MB 流式读取，并要求 PDF 1.4、单页、未加密、无表单、固定 iText 生成器和完整文本层。
- 共享解析核对期号、日期、七个号码、七个基础奖级、一二等奖追加奖级、固定奖档、追加 80% 及每行总奖金乘法；支持 PDFBox 已观察的两种行序和 PDFKit 实测列序，任一变化均失败关闭。
- Android 16 物理机已使用公开 `26090` 期完成主 JSON、聚合回退、真实 PDFBox 文本层和双证据结果。iOS 26.5 Simulator 早期曾对中国体彩网证书链返回 `NSURLError -1202`；2026-08-17 在明确移除验收代理后，项目 Darwin 客户端已完成同一期主 JSON、聚合回退、官方 PDF 下载、PDFKit 文本层和双证据结果，没有绕过 TLS 校验。

### 双色球

- `findDrawNotice` 为主源，`forIssue` 只辅助核对号码和一至六等奖，不能单独驱动 `FINAL_NUMBERS`。
- 已核验 `2026014` 至 `2026075` 为特别规定期间；后续期次仅在主接口显式提供全部已知活动字段且均为空、详情接口严格一致时解释为普通状态。
- 政策字段缺失、类型漂移或任一已知活动字段非空时返回 `PUBLISHING` 或数据源异常，不得把字段缺失猜成普通状态。
