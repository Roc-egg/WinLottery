# V1.3 历史走势与数学预测交付记录

文档状态：会话级技术范围已完成；完整版本受数据授权阻断

立项日期：2026-08-26

当前稳定版本：`1.2.0 (4)`

目标平台：Android、iOS

## 1. 当前目标

V1.3 已完成 Android/iOS 共用的真实历史开奖基本走势与数学研究：官方历史开奖会话采样、五档样本、遗漏统计、共享 Compose 页面、固定候选策略和 450 期样本外回测均已落地并通过双虚拟机验收。当前没有待实现的会话级功能；长期持久化和完整版本关闭仍等待历史数据授权。

## 2. 冻结边界

- 大乐透支持前区 `01..35`、后区 `01..12`；双色球支持红球 `01..33`、蓝球 `01..16`。
- “当前往前”统一解释为以官网当前最新已发布期为锚点，样本范围固定为最近 `50 / 80 / 120 / 300 / 500` 期。
- 每个彩种首次进入走势图时最多加载 500 期；彩种内的号码区域和样本档位切换只使用当前控制器会话内存，不重复请求官网。
- 不使用演示开奖兜底。网络或官网结构失败时展示明确失败状态，只允许用户主动重试，不把缺失数据解释成真实走势。
- 命中格显示号码圆点，未命中格显示截至该期的样本内遗漏值；号码表头后先展示出现次数、当前遗漏和最大遗漏，再展示各期开奖行。
- 图表显示真实样本数量、起止期号、缺期状态、官方来源和本次获取时间；连线只表达相邻期命中位置，不表达因果或中奖概率。
- 走势图、状态和计算均位于共享模块，不为 Android 或 iOS 分别实现业务口径。
- 当前只允许用户操作触发的低频会话采样；不新增历史开奖 Room 表、不保存官网原始响应、不后台轮询、不长期归档。
- 数学研究固定使用 `frequency-omission-ranking-v1`、50 期训练窗口、450 期时间前推回测和均匀随机精确理论基线，不根据结果事后调参。

## 4. 完成条件与关闭边界

- 共享数据测试覆盖分页、玩法标识、发布状态、期号、日期、号码范围、唯一性、顺序、重复记录、来源漂移和网络失败。
- 共享领域测试覆盖号码越界、重复号码、重复期号、乱序、跨彩种、缺期和冲突。
- Android/iOS 共用页面支持彩种、号码区域和五档真实样本切换，横向矩阵在双端标准字号和横屏下不重叠。
- 页面最后一期必须等于验收时官网最新已发布期，样本档位必须展示精确的实际期数；静态演示期号不得进入正式验收。
- 预测策略可由历史快照、算法版本和参数复现，并按时间前推与均匀随机基线比较。
- 固定双虚拟机、共享测试、双端 Release、基本走势和数学研究均已满足当前会话技术范围；完整 V1.3 仍需取得长期存储、分析和再展示授权，或切换到明确授权的数据源。

### 2026-08-26：数学策略与回测协议冻结

- ADR-023 已采用。首发只实现 `frequency-omission-ranking-v1`：最近 50 期内按出现次数升序、当前遗漏降序、号码升序确定性选出一注候选，不开放参数调节或事后策略切换。
- 最近 500 期按时间前推形成 450 个样本外目标期，每个目标期只能看到此前 50 期；生产候选和回测必须调用同一策略实现。
- 主号码、次号码分别展示策略平均命中数、均匀无放回选号的精确理论期望 `k² / N` 和差值。当前阶段固定说明尚未证明稳定优于随机，不使用中奖个例、奖金或稀疏奖级作宣传。
- 历史开奖仍只存在当前控制器会话内；本阶段不新增 Room 表、网络请求、后台任务、收藏或分享。
