# V1.3 历史走势与数学预测交付记录

文档状态：进行中
立项日期：2026-08-26
当前稳定版本：`1.2.0 (4)`
目标平台：Android、iOS

## 1. 当前目标

V1.3 优先交付 Android/iOS 共用的基本走势图。首批实现历史开奖领域模型、号码区域规格、出现次数、当前遗漏、最大遗漏和期号号码矩阵，再接入共享 Compose 一级页面。

## 2. 冻结边界

- 大乐透支持前区 `01..35`、后区 `01..12`；双色球支持红球 `01..33`、蓝球 `01..16`。
- 样本范围固定为最近 `10 / 20 / 30 / 50` 期。
- 命中格显示号码圆点，未命中格显示截至该期的样本内遗漏值；底部展示出现次数、当前遗漏和最大遗漏。
- 图表显示样本数量、起止期号、缺期和冲突状态；连线只表达相邻期命中位置，不表达因果或中奖概率。
- 走势图、状态和计算均位于共享模块，不为 Android 或 iOS 分别实现业务口径。
- 首阶段只使用测试夹具、明确标记的演示快照或当前会话内合法取得的数据。未获得授权前不新增历史开奖 Room 表、不批量采集、不后台轮询。
- 数学预测不与首批走势图捆绑实现，必须先冻结算法、参数、时间前推回测和均匀随机基线。

## 4. 完成条件

- 共享领域测试覆盖号码越界、重复号码、重复期号、乱序、跨彩种、缺期和冲突。
- Android/iOS 共用页面支持彩种、号码区域和样本范围切换，横向矩阵在标准与最大辅助字号下不重叠。
- 受控演示快照始终有清晰标识，不与实时官方开奖数据混淆。
- 获授权历史数据能通过显式 Room 迁移长期保存，修订与来源冲突不会进入图表或预测输入。
- 预测策略可由历史快照、算法版本和参数复现，并按时间前推与均匀随机基线比较。
- 固定双虚拟机、共享测试和双端 Release 构建通过后，才能评估完整 V1.3 关闭。
