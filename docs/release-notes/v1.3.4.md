## 本版更新

### 修复

- **Android：拍照或导入图片后识别票面时闪退**。正式包的代码裁剪删掉了本地 OCR 推理引擎回调所需的方法，开始识别即退出；1.3.2、1.3.3 的 Android 安装包均受影响。iOS、macOS 与 Windows 不受影响。

### 升级说明

- 从 1.3.3 覆盖安装，票据记录和本机开奖数据完整保留。
- 从 1.3.2 或更早版本升级时，本版同时包含 1.3.3 的全部更新：首次启动会自动升级本机数据库，升级后旧版本无法打开新的本机数据，如需降级请先在“记录”页导出备份。详见 [1.3.3 版本说明](https://github.com/Roc-egg/WinLottery/releases/tag/v1.3.3)。
