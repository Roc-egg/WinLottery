## 本版更新

### 新功能

- **全新界面**：四个平台的共享界面全面改版。浅灰底配纯白卡片和更明亮的品牌红蓝，大圆角与胶囊按钮；一级页面使用大标题，号码球统一为带轻微立体感的新样式，宽度不够时自动缩小。
- **深色模式与主题设置**：新增完整的深色配色。在“关于与隐私”的“外观”中可选跟随系统、浅色或深色，默认跟随系统，选择保存在本机；手动选择后，状态栏、键盘和系统弹窗也随之切换。
- **液态玻璃底部导航**：手机竖屏的底部导航改为悬浮的玻璃胶囊，透出下方内容的模糊色彩，切换页面时选中块会拉伸回弹。宽屏桌面仍使用左侧导航，手机横屏仍使用顶部紧凑导航。

### 改进

- 首页改为红色主卡加拍照入口，另有导入图片和手动录入入口；说明中补充了快乐8。
- 开奖核对结果顶部直接给出结论，中奖时大字显示税前奖金合计；开奖号码、逐注结果和官方证据改为卡片展示。
- 选号、记录、AI 分析、票面确认和关于页改用统一的分段选择、加减控件和提示条；走势图的页签和筛选菜单同步更新样式。

### 升级说明

- 从 1.3.6 覆盖安装，票据记录、本机开奖数据和 AI 连接配置完整保留，本机数据库不需要升级。
- 主题选择单独保存在本机，不进入票据记录或导出包。
- Android 11 及以下系统不支持背景模糊，底部导航显示为接近不透明的磨砂底色，其他功能不受影响。
