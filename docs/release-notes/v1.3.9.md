## 本版更新

### 新功能

- **版本更新检查**：应用启动时，若距上次检查超过 24 小时，会向 GitHub 读取一次本项目最新正式发布版；发现新版本时在首页弹出提示，显示新版本号、发布日期和本版更新内容，可选择下载新版、跳过此版本或以后再说。
- **用系统浏览器下载新版**：Android 直接下载 APK，Apple Silicon Mac 下载 DMG，x64 Windows 下载 MSI；iOS 和其他平台打开 GitHub 发布页。应用本身不下载、不安装。
- **“关于与隐私”新增版本更新分区**：显示当前版本号，可以关闭启动时自动检查、查看最近一次检查结果，或随时手动检查。跳过的版本不再自动弹出提示，但这里仍会显示有新版本。

### 隐私与安全

- 检查更新只读取最新发布版的版本号、说明和下载地址，不发送票据、记录、AI 配置或设备信息，也不需要登录。
- 只认本仓库的正式发布版，草稿和预发布版本不会提示；发布页和安装包地址必须指向本仓库，否则不打开。
- 自动检查失败时不打扰，下次启动再试；手动检查失败会说明原因，例如无法连接 GitHub 或访问次数暂时用完。

### 升级说明

- 从 1.3.8 覆盖安装，票据记录、本机开奖数据、AI 连接配置、AI 分析结果和外观设置完整保留，本机数据库不需要升级。
- 自动检查开关、上次检查时间和跳过的版本单独保存在本机，不进入票据记录或导出包。
- 1.3.8 及更早版本没有更新检查，需要手动下载本版；从本版起，之后的新版本会在应用内提示。
