## 本版更新

### 新功能

- **支持中彩快乐8**：拍照或导入快乐8 单式票（选一至选十）后，自动识别玩法、号码、期号和金额，并查询福彩官网开奖核对中奖；结果页列出 20 个开奖号码和每注“选五中三”这样的奖级，奖金按当期官网公布的金额计算。记录页可按快乐8 筛选。快乐8 复式和胆拖票暂不支持；走势、随机选号和 AI 分析仍只支持大乐透和双色球。
- **查看每注命中号码**：开奖核对结果中每注（多期票为每期）下方新增“查看命中号码”，展开后用号码球标出哪些号码与开奖号码相同。
- **AI 分析连接配置保存在本机**：服务商、地址、模型和密钥填写一次即可。Android 和 iOS 用系统加密保存，Windows 与 macOS 不保存密钥；可在 AI 页一键清除。
- **AI 分析支持更多服务**：可选 Anthropic Messages、OpenAI Chat Completions 或 OpenAI Responses 接口格式，填写 Base URL 即可，输入框下方显示实际请求地址；支持本机或局域网的 HTTP 服务（会提示不加密）；模型可从服务商读取列表后点选。

### 改进

- AI 分析失败时显示 HTTP 状态码和服务商返回的错误说明，便于判断原因；说明中出现的密钥会被隐藏。
- AI 分析的输出上限可在 4K 至 32K token 之间选择，默认 8K；推理模型不再因上限过低而提示“结果未完成”。

### 修复

- 点击输入框后键盘弹出又立即收起、输入框失去焦点。
- 键盘弹出时底部导航被顶起、键盘上方出现空白。
- 手动录入时一组号码无法多选成复式。

### 升级说明

- 从 1.3.5 覆盖安装，票据记录和本机开奖数据完整保留，本机数据库不需要升级。
- 新版保存的快乐8 记录，1.3.5 及更早版本无法读取，会提示本机记录已损坏并停止读取；含快乐8 记录的导出备份也无法导入旧版本。如需降级，请先在新版“记录”页删除快乐8 记录。
- 为了连接本机或局域网的 HTTP AI 服务，Android 版允许明文网络连接，iOS 版放开了应用传输安全限制；应用内置的开奖查询仍全部使用 HTTPS。
