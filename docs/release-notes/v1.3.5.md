## 本版更新

### 新功能

- **支持复式票**：拍照或导入大乐透、双色球复式票后，自动按复式展开计算注数和金额；同一张票上既有单式又有复式的套餐票也能一起识别。确认页按“第 N 组 · 复式 X 注”显示，结果页列出每个奖级各中了几注和本组奖金。手动录入时，一组号码多选即为复式。胆拖票暂不支持。
- **横着拍、倒着拍也能识别**：识别前先把整张票转正，票面横置或倒置时不再一注也读不出来，确认页仍在原图上标出各字段位置。

### 改进

- 本地 OCR 模型升级为 PP-OCRv6 small：更多票面可以直接确认，识别速度明显提升（iPhone XS 上识别 13 张真实票的总耗时约减半）。
- Android：升级后自动删除旧版 OCR 模型，不残留约 30 MB 旧文件。

### 修复

- iOS：连续识别多张票时，应用因内存超限被系统结束。
- 票面校验码中含“+”时，误提示“至少一行投注号码不完整”。

### 升级说明

- 从 1.3.4 覆盖安装，票据记录和本机开奖数据完整保留，本机数据库不需要升级。
- 新版保存的复式票记录，1.3.4 及更早版本无法读取，会提示本机记录已损坏并停止读取；含复式票的导出备份也无法导入旧版本。如需降级，请先在新版“记录”页删除复式票记录。
